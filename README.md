# PDA-Lab_1

Лаба 1. Игры собраны с GOG.

## Откуда данные

GOG, у него есть открытый JSON-эндпоинт каталога: https://catalog.gog.com/v1/catalog.

## Как это запускать

Ставим библиотеки: pip install requests pandas sqlalchemy

Сначала запускаем scraper.py. Он пробежится по страницам каталога, соберёт игры и сохранит их в gog.db.

Потом запускаем main.py. Он читает базу и печатает результаты пяти запросов.

## Как подгружать новые данные

Просто запускаем scraper.py ещё раз. Он смотрит, какие id уже лежат в базе, и дописывает только новые игры, так что дублей не будет.

## Что внутри базы

Одна таблица games: id, title, release_date, developers, publishers, genres, price_final, price_base, discount, rating, reviews_count.

## Запросы в main.py

1. Топ-10 разработчиков по числу игр.
2. Средняя цена по жанрам (жанры хранятся строкой, так что режем и разворачиваем).
3. Доля игр со скидкой по годам релиза.
4. Средний рейтинг по годам, только для игр с числом отзывов больше 50.
5. Топ-10 игр по числу отзывов.
